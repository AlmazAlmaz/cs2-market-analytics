# Обновление Almaz v3 — 2026-08-10

> Это исторический отчёт о promotion Almaz v3. Состояние и ограничения Igor
> ниже зафиксированы на момент этой проверки; позднее Igor v2 была независимо
> проверена и обновлена. Актуальный результат:
> [IGOR_UPDATE_REPORT.md](IGOR_UPDATE_REPORT.md).

## Итог

Production-модель Almaz переобучена на актуальном snapshot базы и заменена
атомарно только после сравнения со старой моделью на одном временном holdout.
Предыдущий артефакт сохранён в
`models/backups/almaz_20260809T232401Z/`.

## Данные и разбиение

- строк продаж в snapshot: 795 869;
- строк, пригодных для runtime-контракта: 795 039;
- train: 668 914;
- validation: 74 323;
- untouched test: 51 802;
- test начинается после времени обучения прежней Almaz v2.

Разбиение строго хронологическое. Validation используется для calibration и
early stopping, test — только для финальной проверки.

## Что изменено в модели

- удалены признаки `listing_age_hours` и `watchers`, которых нет надёжно в
  production runtime;
- цель заменена на `log_premium` относительно рыночной reference price;
- добавлена calibration только по validation;
- добавлены q15/q85 для интервала неопределённости;
- training и runtime используют один контракт восстановления абсолютной цены;
- артефакт хранит fingerprint базы, provenance и полный runtime market snapshot;
- запись модели и метрик выполняется атомарно.

## Almaz v2 и Almaz v3

Обе модели проверены на одинаковых 51 802 новых продажах.

|---|---:|---:|
| MAE | $2.3745 | $1.6276 |
| Median APE | 7.2752% | 5.6503% |
| Mean APE | 12.8884% | 11.7288% |

MAE снизилась примерно на 31.5%. Интервал q15–q85 покрывает 71.44% test при

## Сравнение трёх production-артефактов на момент отчёта

На одном наборе runtime-valid строк получена ориентировочная проверка:

| Модель | MAE | Median APE |
|---|---:|---:|
| Igor | $1.4432 | 4.8097% |
| Nova | $1.5823 | 5.0317% |

Это полезное одинаковое runtime-сравнение, но не полностью untouched benchmark
для Igor и Nova: их сохранённые артефакты имеют другие даты и собственные split.
Поэтому сайт показывает консенсус, разногласия и консервативный ROI, а не выдаёт
одну модель за безусловно лучшую.

Таблица выше сохранена без изменений как результат именно того запуска Almaz;
после последующего promotion Igor v2 она больше не описывает текущий Igor
production bundle.

## Ограничения на момент этого отчёта

- В рамках этого запуска Almaz модель Igor не переобучалась: её полный CPU
  pipeline заметно тяжелее по RAM, времени и размеру артефактов. Проверка
  fingerprint/cache уже была добавлена для следующего безопасного запуска.
- Исторические reference prices не являются полноценной time-series на каждую
  дату продажи, поэтому на тот момент абсолютной защиты от исторического price
  leakage не было.
- На тот момент Igor ещё не имела отдельных charms/keychains-признаков и
  исторического reference-контракта для них.

После этого отчёта Igor v2 получила as-of маскирование будущих/неизвестных
reference-значений, отдельные keychain-признаки и общий train/runtime contract.
Это закрывает конкретные найденные источники leakage и рассинхронизации, но не
создаёт отсутствующие исторические reference time-series. Метрики и оставшиеся
ограничения приведены в [отчёте Igor v2](IGOR_UPDATE_REPORT.md).
